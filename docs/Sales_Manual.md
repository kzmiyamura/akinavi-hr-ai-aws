# AkiNavi HR-AI 操作マニュアル
### 営業担当者向け

---

## このシステムでできること

- **人材を登録する**：もらったメールや資料のテキストを貼り付けるだけで、AIが自動で整理して保存します
- **案件を登録する**：案件の概要を貼り付けるだけで保存できます
- **メールで自動登録する**（設定済みの場合）：専用のメールアドレスに転送・送信すると、自動で解析・登録されます
- **マッチングする**：案件と人材を照合して、相性の良い順にランキングで表示します
- **提案を管理する**：誰を・どの案件に・提案したかを記録できます
- **重複を整理する**：同じ人が二重登録されていたら、まとめることができます
- **取り込み状況を確認する**（任意）：メール等の自動取り込みがうまくいったかを一覧で確認できます

---

## はじめての起動

1. ブラウザでシステムのURLを開く
2. **「あなたの名前を入力してください」**という画面が出たら、自分の名前（例: 田中）を入力する
3. **「使いはじめる」**ボタンを押す
4. 次回からは同じブラウザでは入力不要です（このPCのブラウザに保存されます）

> 名前はデータに「誰が登録したか」として記録されます。空欄にはできません（20文字まで）。

## 画面の見方

画面上部のタブで切り替えます。

| タブ | できること |
|---|---|
| 人材登録 | 人材を新規登録・一覧表示・削除 |
| 案件登録 | 案件を新規登録・一覧表示 |
| マッチング | 案件と人材の相性をAIでスコアリング |
| 提案履歴 | 提案のステータス管理 |
| 重複管理 | 二重登録の整理・統合 |
| 解析監視 | メール等の自動取り込みの成功・失敗の確認（詳細は下記） |

## メールで人材・案件を登録する（自動取り込み）

社内で専用メールと連携している場合、次の宛先にメールを送ると、本文・添付が自動で解析され、人材または案件として登録されることがあります。

| 種類 | 宛先メールアドレス（例） |
|---|---|
| 人材として登録 | `akinavi.hr.ai.voice.human@outlook.jp` |
| 案件として登録 | `akinavi.hr.ai.voice.project@outlook.jp` |

- 本文に **Google のスプレッドシートやドキュメントの共有リンク** があれば、開ける設定（リンクを知っている人が閲覧可）になっていれば、そこから情報を読み取ることがあります
- 自動登録の成否は **「解析監視」** タブで確認できます
- 連携の有無・メールのルールは社内担当に確認してください

---

## 人材を登録する（画面から）

1. 「**人材登録**」タブを開く
2. 登録したい人のメール本文・職務経歴・スキルシートなどのテキストをコピーする
3. テキストエリアに貼り付ける
4. 「**解析して登録**」ボタンを押す
5. しばらく待つと「登録完了: ○○ さん」と表示されます（重複の疑いがある場合は、その旨が表示されることがあります）

**ポイント**
- **同じメールアドレス**の人を再度登録すると、情報が最新のものに上書き更新されます
- メールアドレスが本文に含まれていない場合、別人として別々に登録されることがあります

---

## 案件を登録する

1. 「**案件登録**」タブを開く
2. 案件の概要・要件・メール本文などのテキストをコピーして貼り付ける
3. 「**解析して登録**」ボタンを押す
4. 「登録完了: ○○」と表示されれば完了

一覧では、案件の状態（募集中・充足・クローズなど）が表示されます。

---

## マッチングを実行する

1. 「**マッチング**」タブを開く
2. 一覧から対象の**案件を選ぶ**（**募集中の案件だけ**が選べます）
3. 「**AI マッチング実行**」ボタンを押す
4. しばらく待つと、登録されている**全員の人材**についてスコアが計算され、相性の良い順にランキングで表示されます

**スコアの見方**
| スコア | 意味 |
|---|---|
| 80〜100 | 非常に相性が良い |
| 60〜79 | まずまず相性が良い |
| 60未満 | あまり向いていない可能性がある |

> 「重複の疑い」が表示されている場合は、同じ人が二重登録されているかもしれません。「重複管理」タブで確認してください。

---

## 提案状況を記録する

1. 「**提案履歴**」タブを開く
2. 一覧から**案件を選ぶ**（登録されている案件はこちらではすべて選べます）
3. 提案した人材の横にあるボタンで状況を更新します

| 表示 | 意味 |
|---|---|
| 未送信 | まだクライアントに出していない |
| 送信済み | クライアントに提案した |
| 採用 | クライアントがOKを出した |
| 不採用 | クライアントがNGだった |

| ボタン | いつ使うか |
|---|---|
| 送信済みにする | いま「未送信」のとき。クライアントに提案したら押す |
| 採用 | いま「送信済み」のとき。採用が決まったら押す |
| 不採用 | いま「送信済み」のとき。見送りになったら押す |

---

## 重複をまとめる（名寄せ）

同じ人が名前・スキルの表記違いで二重登録されている場合、AIが「重複の疑い」を付けることがあります。

1. 「**重複管理**」タブを開く
2. 一覧に表示された人材を確認する
3. 同一人物であれば「**統合先を選択**」から残したい方を選び、「**名寄せ（統合）**」を押す
4. 別人であれば「**重複ではない**」を押して、疑いフラグを外す

---

## 解析監視タブについて

メールなどで**自動取り込み**したとき、処理が成功したか・失敗したか・どれくらい時間がかかったかを一覧で確認できます。

- 通常は画面から人材・案件を登録するだけの場合、あまり使いません
- 「メールを送ったのに一覧に出ない」ときは、ここでエラーになっていないか確認するとよいです
- 詳しい文言や再実行は、社内の担当者向け説明を参照してください

## よくある質問

**Q. 名前（ニックネーム）を変えたい**  
A. 画面右上の **「名前変更」** を押すと、保存されている名前を消せます。次にページを開き直すと、もう一度入力し直せます。

**Q. 登録した人材を削除したい**  
A. 「人材登録」タブの一覧で、その人の **ゴミ箱（削除）ボタン** から削除できます。**削除すると元に戻せません。** 案件はこの画面から削除できない場合があります。必要なら社内担当へ相談してください。

**Q. AIの解析結果が間違っている**  
A. 一覧に表示された情報は参考です。重要な判断は必ず担当者が目で確認してください。人材の内容は一覧から手直しできる場合があります。

**Q. 「AI解析中...」のまま止まった**  
A. ページを再読み込みして、もう一度お試しください。改善しない場合は担当エンジニアへ連絡してください。
