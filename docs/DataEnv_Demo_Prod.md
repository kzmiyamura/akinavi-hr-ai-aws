# データ環境：本番（prod）とデモ（demo）

このアプリは **DB を1つだけ使い**、`data_env` 列の値で本番データとデモデータを論理的に分けています。

---

## 2つの環境の違い

| | prod（本番） | demo（デモ） |
|---|---|---|
| 用途 | 実際の人材・案件・提案履歴 | 営業デモ・検証用ダミーデータ |
| デフォルト | **常にこちら** | デモ機能オン時に選択可 |
| データの扱い | 本物データのみ表示・登録 | デモデータのみ表示・登録 |
| 切替方法 | デフォルト | `?demo=KEY` の URL を開く |

> **重要**：prod と demo は「論理分離」です。DB に直接 SQL を実行できる人はどちらのデータにも触れます。運用ルールで区別してください。

---

## デモ機能の切替方法

### オンにする

1. 以下の URL をブラウザで開く（`あなたの鍵` は `VITE_DEMO_KEY` の値）

   ```
   https://（アプリのURL）/?demo=あなたの鍵
   ```

2. 鍵が正しければ、画面上部に **「本番相当 / デモ」の切替セレクト** が現れ、**デモが選択された状態**になる
3. URL から `?demo=...` は自動的に消える（アドレスバーに鍵が残らない）

### オフに戻す

**オン状態で**、もう一度同じ `?demo=あなたの鍵` の URL を開くとトグルでオフになり、**本番固定**に戻る。

### 鍵が間違っている場合

何も起きない。引き続き本番（prod）のみの動作。

---

### 切替状態の一覧

| 操作 | 結果 |
|---|---|
| 通常アクセス（`?demo=` なし） | 本番（prod）固定。切替 UI は非表示 |
| `?demo=正しい鍵`（デモ機能オフの状態） | デモ機能オン。切替 UI が表示され、デモが選択される |
| `?demo=正しい鍵`（デモ機能オン済みの状態） | デモ機能オフに戻る。本番固定 |
| `?demo=間違った鍵` | 何も変わらない |

---

### 状態の保存場所

切替状態はブラウザの `localStorage` に保存されます。**別の PC・別ブラウザには引き継がれません。**

| 保存内容 | localStorage のキー |
|---|---|
| どちらの環境を選んでいるか | `akinavi.dataEnv.v1` |
| デモ UI を表示するかどうか | `akinavi.demoUnlock.v1` |

---

## デモ用サンプルデータの一括投入

デモ機能がオンで **デモを選択中** のときだけ、画面に **デモシードパネル** が表示されます。  
投入されるデータは `data_env = demo` のみで、**本番データには一切触れません。**

---

## メール自動取り込みと prod / demo

Outlook からの自動取り込み（`poll-email` → `inbound-email`）は、**メールアカウントごとに保存先が決まっています。**

| メールアカウント | 保存先 |
|---|---|
| 本番用（human / project） | `prod` |
| デモ・開発用（human-dev / project-dev） | `demo` |

どのアカウントがどちらに対応するかは、Supabase Secrets の `GRAPH_REFRESH_TOKEN_*` と `poll-email` の設定で決まります（詳細は README.md の Secrets 一覧を参照）。

`inbound-email` を直接呼び出す場合は、リクエストの `data_env` パラメータで指定できます。

## よくある質問

**Q. `VITE_DEMO_KEY` を設定しないとどうなる？**

A. デモ切替 UI が実質使えません。常に本番（prod）のみの動作になります。

---

**Q. prod と demo で ID（UUID）は重複する？**

A. 重複しません。同じ人物を prod と demo の両方に登録した場合、DB 上は別の行・別の ID として2件存在します。

---

**Q. デモデータを本番に昇格させることはできる？**

A. 自動的にはできません。必要な場合は DB 上で `data_env` を `demo` から `prod` に手動で UPDATE してください。

---

**Q. セキュリティ上の注意は？**

A. `VITE_DEMO_KEY` は「デモ UI を表示するための共有秘密」程度の位置づけです。  
本番データを外部に絶対見せてはいけない要件がある場合は、ネットワーク制限や Supabase の別プロジェクト分離も検討してください。
