# AkiNavi 常駐PC セットアップ手順（操作する方へ）

このPCに「AkiNavi の裏方プログラム」を入れます。
**難しいことは Claude Code が全部やります。** この紙のとおりに進めてください。

所要時間は 30分〜1時間ほどです（待ち時間が長く、実際に手を動かすのは数分です）。

---

## 用意するもの

1. **このPC**
2. **`akinavi_shadow.env` というファイル**
   宮村さんから LINE WORKS で届きます。**PCに保存しておいてください**（ダウンロードフォルダでOK）。
   中身を開いたり、書き写したりする必要はありません。
3. **会社の Claude アカウントのログイン情報**（メールアドレスとパスワード）

---

## 手順1: Claude Code を開く

デスクトップまたはスタートメニューから **Claude Code** を起動します。
文字を打ち込める画面が出ればOKです。

---

## 手順2: 下の1行をコピーして貼り付け、Enter を押す

```
scripts/llm_extract/SETUP_company_pc.md を読んで、上から順に最後まで実行してください。私はエンジニアではありません。
```

これだけです。あとは Claude が自分で進めます。

---

## 手順3: 聞かれたら答える

Claude は途中で何度か聞いてきます。**聞かれるのは次の3つだけ**です。
それ以外のことは Claude が自分で判断して進めます。

### ① 「Claude にログインしてください」と言われたら

ブラウザが開くので、**会社の Claude アカウント**でログインしてください。
終わったら Claude Code の画面に戻って「ログインしました」と伝えます。

### ② 「設定ファイルの場所を教えてください」と言われたら

宮村さんから届いた **`akinavi_shadow.env` を保存した場所**を伝えます。
だいたいは次のように答えれば通じます。

```
ダウンロードフォルダにあります
```

見つからないと言われたら、ファイルを右クリック →「パスのコピー」で出てくる文字列を貼り付けてください。

### ③ 「実行してよいですか」と聞かれたら

Claude は作業のたびに確認を出すことがあります。
**この手順書に沿った作業であれば、承認して進めて構いません。**

判断に迷ったら、そのまま画面を宮村さんに送って聞いてください。

---

## 手順4: 終わったら報告する

Claude が最後に**報告文**を出します。
それを丸ごとコピーして、**LINE WORKS で宮村さんに送ってください**。

これで完了です。

---

## 終わったあとのお願い

このPCは**電源を入れっぱなし**にしてください。
このプログラムは5分おきに動き続けていて、PCが止まると新しい人材データの処理が止まります。

- 画面が消えるのは問題ありません
- **シャットダウン・スリープはしないでください**（設定は Claude が行います）
- Windows の更新で再起動がかかった場合は、そのまま放置で自動復帰します

---

## うまくいかないとき

**やり直しても壊れません。** 落ち着いて次のどれかをしてください。

| 状況 | どうするか |
|---|---|
| Claude がエラーを出して止まった | 画面をスクリーンショットして宮村さんに送る |
| 何を聞かれているか分からない | 画面をそのまま宮村さんに送る |
| 途中で閉じてしまった | Claude Code を開き直して、手順2をもう一度やる |
| ファイルが見つからないと言われる | LINE WORKS からもう一度ダウンロードして、保存先を確認する |

**判断に困ったら進めずに宮村さんに聞いてください。** 急ぐ作業ではありません。
