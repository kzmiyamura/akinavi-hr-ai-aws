# LINE WORKS で設定ファイルを送る手順（宮村さん用）

会社PC（営業部隊が操作）へ渡すファイルを LINE WORKS で送るための手順。
**LINE WORKS は別PCで使う**前提。

送るのは2回。**事前**と**カットオーバー直前**。

---

# 1回目: 事前（接続設定を送る）

## STEP 1. このPC（ThinkCentre）でファイルを取り出す

```
node scripts/llm_extract/prepare_transfer.mjs
```

デスクトップに `akinavi_setup_send` フォルダができる。中身は2つ。

| ファイル | 中身 | 1回目に送るか |
|---|---|---|
| `akinavi_shadow_env.txt` | 接続設定（2行）| **送る** |
| `akinavi_shadow_state.txt` | 処理状態（1行）| 送らない（2回目で送る）|

> ホーム直下の `.akinavi_shadow.env` は先頭がドットでエクスプローラーから扱いにくく、
> 拡張子 `.env` は添付を弾かれることがあるため `.txt` にして取り出している。
> 受け取り側の Claude が正しい名前に戻すので、リネームしないこと。

## STEP 2. LINE WORKS を使うPCへ移す

`C:\Users\admin\Desktop\akinavi_setup_send` を開き、
**`akinavi_shadow_env.txt` だけ**を USB・社内共有・OneDrive などで移す。

## STEP 3. LINE WORKS で営業の担当者に送る

1. LINE WORKS を開き、担当者とのトークを開く
2. 入力欄の**クリップ（添付）アイコン**から「ファイル」を選ぶ
3. `akinavi_shadow_env.txt` を選んで送信
4. 続けて、下の**メッセージ本文**を貼って送る

### 一緒に送るメッセージ（コピーして貼る）

```
AkiNavi の常駐PCセットアップをお願いします。
所要 30分〜1時間ほどですが、待ち時間が大半で、実際に手を動かすのは数分です。

【事前に】
送ったファイル「akinavi_shadow_env.txt」をPCに保存しておいてください。
（ダウンロードフォルダでOK。中身を開いたり書き写す必要はありません）

会社の Claude アカウントのログイン情報も手元に用意してください。

【手順】
1. PCで Claude Code を起動する
2. 下の1行をコピーして貼り付け、Enter を押す

scripts/llm_extract/SETUP_company_pc.md を読んで、上から順に最後まで実行してください。私はエンジニアではありません。

3. あとは Claude が自分で進めます。
   途中で聞かれるのは次の3つだけです。

   ・Claude へのログイン
     → ブラウザが開くので会社のアカウントでログインし、
       「ログインしました」と伝えてください

   ・設定ファイルの場所
     → 「ダウンロードフォルダにあります」と答えてください

   ・実行してよいか（承認）
     → この手順に沿った作業なら承認して進めて構いません

4. 最後に Claude が「報告」を出します。
   それを丸ごとコピーして私に送ってください。

【注意】
・すでに準備が終わっているものがあっても大丈夫です。
  Claude が判断して飛ばします。二度手間にはなりません。
・途中でやり直したくなったら、同じ1行をもう一度貼れば続きから進みます。
・エラーが出たり、何を聞かれているか分からないときは、
  進めずに画面のスクリーンショットを私に送ってください。急ぎません。
・終わったら、このPCは電源を入れっぱなしにしてください。
  （画面が消えるのは問題ありません。シャットダウンだけ避けてください）
```

## STEP 4. 送信後の後始末

**キーが平文で残っている場所を消す。**

- このPC:
  ```powershell
  Remove-Item -Recurse -Force "C:\Users\admin\Desktop\akinavi_setup_send"
  ```
- 移送に使った USB / 共有フォルダからも削除する
- LINE WORKS の送信済みファイルは、会社の運用方針に従う

# 2回目: カットオーバー直前（処理状態を送る）

営業から「準備ができました」「元のPCを止めてください」と連絡が来たら行う。

## なぜもう一度送るのか

`akinavi_shadow_state.txt` には**どこまで処理したか**と**その日の処理件数**が入っている。
これは5分ごとに更新され続けるので、**旧PCを止める直前のものでないと意味がない**。

引き継がないと、未処理分の取りこぼしか、処理済み分の再処理（AI利用枠の無駄）が起きる。

## STEP 1. ファイルを取り出して旧PCを止める

**この順番で実行する**（先に止めてから取り出すのでも可。同時稼働を避けるのが目的）。

```powershell
node scripts/llm_extract/prepare_transfer.mjs
pm2 stop akinavi-shadow
pm2 delete akinavi-shadow
pm2 save
```

**`pm2 save` まで必ず実行する。** 忘れると次回ログオン時に
スタートアップの復元処理でこのPCのワーカーが復活し、二重稼働になる。

停止の確認:

```powershell
pm2 list
```

`akinavi-shadow` の行が消えていること。

## STEP 2. LINE WORKS で送る

`akinavi_shadow_state.txt` を1回目と同じ要領で送る。

### 一緒に送るメッセージ（コピーして貼る）

```
元のPCを止めました。
送ったファイル「akinavi_shadow_state.txt」を保存して、
Claude に「元のPCが止まりました。akinavi_shadow_state.txt が届いたので続きをお願いします」
と伝えてください。

Claude が最後まで進めて、報告を出します。
それをまた送ってください。
```

## STEP 3. 後始末

1回目と同じ。`akinavi_setup_send` フォルダと USB から削除する。

# 送ったあとの確認

営業から届く報告に、次が入っていることを見る。

- `pm2 list` の status が `online`、`↺`（再起動回数）が増えていない
- ログの最終行に `サイクル完了` が出ている
- 状態ファイルが「旧PCからコピー」になっている（「新規初期化」なら取りこぼしが出る）
- 「管理者権限が必要で実施できなかった項目」— あれば情シスへの依頼にまとめる
